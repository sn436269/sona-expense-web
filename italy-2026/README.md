# 那些在義大利的日子

SONA 的 2026 冬日旅行手札，靜態部署在 GitHub Pages：

https://sn436269.github.io/sona-expense-web/italy-2026/

從 Clarice de’ Medici「學習、工作與生活」個人首頁下方的「那些在義大利的日子｜2026 旅行手札」連入。

依據 106 張對話中已列明的圖庫截圖（27 張完全重複、79 張不同截圖）、本人補述及本人提供的行程表，整理 2026/1/23～2/8；另保留 1/22 的待確認頁。不同截圖內仍存在重疊縮圖。沒有把截圖時間當成拍照時間，也沒有把貨架標價當成實付金額。

- `index.html`：可直接閱讀的完整逐日內容，不依賴 JavaScript 取得正文。
- `styles.css`、`app.js`：綠白紅主題、手機日期導覽、搜尋、城市篩選、全文列印。
- `italy-2026-itinerary.txt`、`italy-2026-itinerary.md`：完整文字稿下載。
- `itinerary.json`：結構化內容，供後續核對修訂；更改後需同步重建 HTML、TXT、Markdown。

網站沒有上傳原始截圖、票券 QR Code、訂位碼或本機檔案路徑。全文中的 S001～S106 是本機整理資料夾的核對編號。

這是照片重建稿，所有推定／衝突均保留在逐日備註，不能作為已驗證的逐分鐘紀錄。正文及程式的變更不涉及現有私人帳本或日記資料。
